## 已对齐的行为

| 环节 | Q8 规则 |
| --- | --- |
| 首次触发 | 沿用原类别融合门槛和地图资格检查；单帧检测分数只选图片，不作为触发阈值 |
| 候选记忆 | 每个 `(episode_token, candidate_id)` 严格保留可用目标类 crop 中检测分数最高的最多5张；允许不足5张、允许相似图；同分才用完整性、像素数、新旧顺序确定性打破平局 |
| 第一次 Qwen | 只送该候选最高分的一张，返回判定、质量及类别置信度 |
| 清晰明确否定 | 质量 adequate 且 rejected：排除该候选，不补拍，不进入后期靠近集合 |
| 不确定／质量不足 | 保留候选；没有其他已确认且可达目标时，至多安排一次有界主动观测 |
| 观测路径 | 从同簇 RGB-D 可见三维范围、地图尺度、相机高度和固定 FOV 算距离；在已知自由空间的环带选可达短弧，不绕完整圈、不穿未知或膨胀障碍 |
| 朝向 | 当前机器人只能前进／转向，不能边侧移边一直盯着物体。行进服从碰撞安全；在每个采样点朝向物体中心取图，无抬头低头 |
| 第二次 Qwen | 完成路径并取得朝中心的同步观测后，一次联合发送此刻该候选全部 Top-5（1–5张），输出一个联合判定和分数 |
| 补拍图未入选 | 用户明确选择严格按检测分数保留；因此补拍图可能全部不入选。日志记录 `new_view_images`，不把移动后再次请求误称为必然利用新证据 |
| 400步后 | 不再开启新观测绕行；进行中的绕行到400步终止，保留已取得分数。已确认可达目标优先，否则按**最新一次 Qwen 分数**从高到低尝试可达候选；未调用Qwen的候选最后按融合分数后备 |
| 靠近／结束 | 原 `searchObjectPath`、局部动作、碰撞、到达／STOP 逻辑不改；不把 uncertain 提升为 confirmed，不改真实融合或Qwen分数 |

候选图仍需通过既有最低可用性检查（mask至少64像素、短边至少8像素、目标标签）；不是任意坏图也占名额。关联使用地图原 mask 回执，不用在线真值。每候选最多2次完整逻辑复查；一个联合请求不算5次复查。

**盆栽判定与旧 Q6-plant060 的区别必须明确：** Q8 遵循本次“质量不足补拍、清晰否定排除”的最新选择，因此仅 adequate 且非 rejected 的盆栽回答按类别分数 ≥0.60 确认；质量不足即使打分很高也先补拍。旧 `linked_framing` 的原 plant060 规则没有改写，旧数据不重标记。其他五类仍用原结构化判定及 adequate 质量条件。

## 距离、路径与泛化边界

- 距离继承 Q6 的固定视场几何（可见 mask/depth 的稳健三维边界、相机高度、目标投影范围与取景余量），组合 Top-5 的可见高度信息；保留1.1米最小表面距离与4.5米上界。缺深度时保守退远；估计不可取景时退出观测，不强行执行。
- 环带在建议半径及其外侧搜索，离散15°采样；选择最多30°短弧，狭窄空间允许可行的15°弧，至少两个不同采样位置。接近环带的路可从带外开始，后续弧段和实际0.25米前进都须留在已知自由环带。
- 每次观测最多48个真实动作、连续无平移最多24步，并受400步阶段边界限制。无安全路径、地图更新使路线失效或预算不足时停止补拍；已有候选和Qwen分数保留，无额外API调用。
- 植物模型破碎／深度噪声用已观测几何和稳健范围缓解，不缩机器人碰撞尺寸，不借任务真值补全不存在的几何。狭窄空间可能没有可行环带；不能保证物体全貌可见。
- Top-5相似图不等于五份独立证据。多图提示词要求联合判断并处理矛盾；Qwen评分仍未校准，不能直接当类别真实概率或导航成功率。

Q8撤回Q7的目标强制保持、冷却、区域记忆和新脱困策略，也取消Q6的“400步前未确认禁止进入原高融合靠近队列”。首轮／补拍完成后，未被明确排除的高融合候选仍可按原方式靠近。它是 **Q2/ApexNav导航骨架＋Q6复查接口的组合新版本**，不能声称与历史Q2逐步完全相同。

## 原生探索与可选前沿朝向

本地 `FrontierMap2D::isSatisfyFrontier` 当前实际使用**邻接自由栅格的未知栅格**作为前沿种子，排除膨胀障碍；对更新区域搜索、连通聚类、过滤小簇并拆分过大簇，得到前沿中心。不是凭VLM生成前沿点。

`hybridExplorePolicy` 在语义价值有明显差异时筛选高语义价值前沿并用ATSP安排访问次序，否则选A*路径最近的前沿。局部动作朝路径方向前进；原实现没有独立的“到点后朝未知边界看”终端姿态。前沿被当前视野看到或其连通未知区太小时可转休眠；局部可见不等于房间已经完整覆盖。

独立开关 `--frontier-look` **默认关闭**：只在抵达前沿附近、当前仍处于探索且没有更优物体靠近任务时，按原规划器视场参数估计可见的未知边界增益；射线遇障碍／地图边界停止，不穿墙计算收益。根据每次转向的新增可见边界选择方向，单次最多3个30°转向；无新增收益不转，原地不反复扫描。生成、聚类、前沿路由和碰撞不变。单独消融，不能将其收益与多图环带混在一起。
