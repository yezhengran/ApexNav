# Q8-C：最佳 crop 拍摄距离备用弧

2026-11-16，用户要求：原观测圈不可用时，不逐级缩圈，改用该语义候选最佳 crop 的拍摄位置到物体中心的水平距离生成观测弧。另核对多个候选的 Qwen 调用顺序。本次只实现与离线验证；**459／462没有重跑，401–500继续暂停**，不把几何示意当作实际可通行地图或新成绩。

## 方法与开关

仍在 `codex/objectnav-annular-top5`，基于 `825c82c`，方法标记为 **Q8-C + crop-pose-fallback**。`docker/run_batch.py` 新增 `--crop-pose-fallback`，仅允许 `--review-profile linked_choice`；不传开关保留原观测策略。原 Q8-C 的融合或最佳目标 crop 检测分 >0.7 入口、多候选比较时机、严格 Top5、Qwen 判定、靠近与 STOP 均不改。

1. 先尝试原固定视场全貌环带。只有初始几何不可用，或规划器未找到完整初始观测路径、且尚未执行任何观测动作时，才尝试一次备用弧。已开始执行后发生受阻，不重新生成备用弧。
2. 从当前该 mapper 候选严格 Top5 中取检测分最高的可用 crop；读取其原始 NPZ 中的真实拍摄 XY，并核对身份／mask／位姿／边界。圆心仍是此次请求中的语义候选中心。半径严格等于二者水平欧氏距离，不用当前机器人位置替代历史拍摄位置，不使用真值或逐级缩圈。
3. 以“候选中心指向最佳拍摄位置”的方向为中线，左右各30°，径向允许范围为实测半径±0.25米；采样点在精确实测半径上，每15°一点，共5个待筛位置。沿用既有0.6–4.5米搜索范围，越界则放弃，绝不把半径夹到边界。
4. 所有候选点依旧检查已知自由空间、膨胀障碍和到物体近表面的视线；A*找入口，整段路径按0.025米复查，后续弧段与量化前进动作必须处于安全距离带。选择2–3个点、最多30°的一小段路径，并非走完整个圆。近距离下跳过到达圆盘重叠的相邻采样点，避免原地被计成两次观测；若仍不能构成两点短弧则放弃。
5. 每个到达点朝向物体中心，误差≤18°才记采样。移动过程朝向由路径控制，不承诺持续正对物体。原48动作／24动作无平移监控、400步截止、每候选最多两次完整复核共用，不重置预算或网络次数。
6. 路径完成后按原规则把该物体此刻最高检测分的1–5张图联合交给 Qwen；允许补拍图未进入 Top5。备用弧只以已拍到图的距离增加找到视点的机会，**不再承诺满足原全貌几何下界**；最终图像质量仍由 Qwen 判断。找不到弧则保持首次不确定结果，不凭几何提升确认。

新增 `inspection_crop_pose_fallback` 保存精确来源、原半径、实测半径与扇区；规划器 `[Annular search]` 分别记录几何采样数、通过自由空间／视线／入口路径的数量及可行短弧数。离线审计核验首次失败回执、最高分来源与像素、半径、扇区、到达、两次复查限制和有序 HTTP 账本。原失败证据不重写。

## Qwen 调度对齐

目前是**同步、串行、阻塞导航**。`ExplorationFSM::maybeReviewAutomatic` 在规划前按候选ID依次请求合格候选的初审；`habitat_evaluation.py` 等待 HTTP 返回并原子提交结果，再通知规划器 `ACTION_FINISH`。等待时不执行 Habitat 导航步，也不是机器人边走边等待的异步旁路。

- 若同一时刻有A／B两个不同候选都符合初审条件，会先审A、再审B，处理完这些初审才执行下一段导航／观测动作。只符合保存条件而未满足初审门槛的候选，不会强制调用。
- 若A／B都是不确定，先完成两者初审，再按可用性选择一个做观测；两条观测路径不会并行。若有已确认且可达的替代目标，其他不确定候选的补拍被抑制。
- 若是同一物体的两张图，不代表两次独立调用：首次用最佳一张；观测完成后把该物体Top5（实际1–5张）放在一次联合请求里。
- 用户已定的多候选比较仍仅在“400步前多个候选均已确认”或“400步后无已确认目标”触发，也同步等待选择结果。相对选中不等于类别确认。
