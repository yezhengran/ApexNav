# Q5：朝向后复查＋类别置信度加权

2026-11-14 用户要求在 Q4 基础上修改并重跑原演示第 10（chair）、885（tv），已确认融合 0.5＋Qwen 0.5。独立分支 `codex/objectnav-facing-confidence-review`，profile `linked_confidence`；本轮只做两个固定身份的演示，原 Q4-fail30 和全量失败分析保持暂停。

## 约定与实现

- **触发**：沿用原类别融合阈值和原观测资格；chair 0.50、tv 0.45、potted plant 0.40（其他类别见版本登记）。不是单帧 0.65 触发。
- **图像**：按地图候选 ID、回合 token 和原 mask 关联回执绑定，实时保留一个最高检测分数的可用 crop。分数相同按完整性、像素数、新近程度和 mask 索引决定。每次改善的缩略图另作历史审计，不构成多个在线输入候选。
- **二次复查**：首次未确认，且无其他可达已确认目标时，仍按原安全点位、路径和平移/转向规则寻找观测点。到点、朝向物体估计中心（原规划容差 18°）、取得并整合真实观测后，才允许第二次 API 调用。取消 Q4 观测途中提前调用。输入取调用时该对象的全历史最佳 crop，允许复用第一次的图；朝向就绪时机和输入图来源分别记录。
- **失败边界**：48 个观测动作、24 步无平移、无安全点位等退出条件保留；未达到朝向条件，不在退出时偷偷补发二次调用。每个候选最多两次完整复核。
- **Qwen 分数**：新增严格 JSON 字段 `target_confidence`，有限数值 [0,1]；表示 crop 属于目标类别的模型自报把握，不是对 `uncertain` 标签的把握，也不是经校准的概率。无字段、布尔、越界或异常回答仍停止。使用最近一次完整回答的分数，不取历次最大值。
- **400 步后**：对原导航候选队列中的未确认对象，排序分数为 `0.5 * fusion + 0.5 * target_confidence`；未调用 Qwen 的候选保持 fusion 分数。已确认优先级、拒绝排除、类别/观测数/原高置信资格及队列路径可达性检查保留；不把低融合候选提升进原高置信队列。原探索、靠近路径和几何到达/STOP 判定不变。分数不直接授予 STOP 或导航成功。
- **原子交接**：结果与数值一起通过 `ScoredReviewResult` 发送，检查回合、观测和候选；同回调写分数后才重规划/确认回执。旧 profile 仍用原消息和原提示词。
- **费用**：原共享 20 元账本，起点 1.300285 元。保持原请求/episode 有界网络恢复和每 HTTP 尝试预留；不清除旧失败预留。
