# Q6：固定相机的高度与视场自适应观测

## 假设与范围

用户从 Q5 演示发现观测点过近：低处的椅子、高处墙面电视容易被画面上下边缘截断。三维质心能表示高度偏移，但不能表达物体是否完整进入视场，因此本轮用可见三维范围和相机视场计算距离。只固定重跑全局第 10（chair）与 885（tv），各保留首个完整结果，不扩大选例、不恢复旧 30/1000、不修改旧结果。

分支：`codex/objectnav-height-aware-viewpoint`；父提交：`803a20c24ed516ef4af3f020097b0a85e9b6917a`。新增可选 profile `linked_framing`，简称 **Q6 高度视场观测版**。Q5 `linked_confidence` 和其他旧 profile 保留。

## 实现

- 地图仍决定候选 ID、融合触发阈值和水平朝向中心。使用该 ID 的最佳检测图所绑定的原始 mask/depth，反投影三维可见点；仅采用落在对应地图簇水平边界附近的深度点，取 5–95% 高度分位数，并记录三维中位中心。无任务真值输入。
- 使用实际相机参数：640×480、水平视场 79°、传感器安装高度 0.88 米，加上当前机器人 GPS 高度。物体高度与相机高度都在同一坐标系；估计不能替代不可见部分的真实完整尺寸。
- 取中央 80% 画面作为取景区域，给高度边界留至少 0.12 米余量；原 mask 碰到图像边缘时至少 0.25 米。水平范围由地图包围盒的保守外接圆覆盖，另计既有 18° 朝向量化误差。
- 同时满足高度、水平取景与至少 1.1 米表面间隔；观测目标半径另加 0.3125 米到点误差。无可靠深度时明确记录回退，仅增加间隔，不声称满足高度取景。估计所需半径超过 4.5 米或固定俯仰无法容纳时，结束该次观测尝试并保持不确定，不压缩距离伪装满足条件。
- 原安全/可见性/A* 路径检查保留；优先搜索计算半径的 24 个点，再尝试增加 0.35/0.70 米的两圈（最大 4.5 米）。到点还需满足实际最小距离；仍朝向物体水平中心后取得真实观测，再允许第二次复查。48 动作/24 无平移上限保持，无新增抬头低头动作。
- Q5 的模型、提示词、最高单帧分数 crop 选择、每候选两次完成复查、400 步后 0.5 融合＋0.5 Qwen 排序、原到达条件及网络/预算规则均不变。较远观察后的图像不一定成为 VLM 输入：仍可能使用之前保存的最高分图。
