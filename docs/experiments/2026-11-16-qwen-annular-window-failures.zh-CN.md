# Q8 第400–500回合：27个失败的离线分析

2026-11-16按用户要求，仅分析已有失败原因、类别与距离，不提出后续算法修改方案，不重跑导航。前沿朝向开关的实现是另一个已授权改动，**这些历史失败全部发生在frontier-look关闭时**，不能用本分析宣称新开关提高成功率。

## 数据与核查方法

固定HM3Dv2 val 400–500共101例，Q8成功74、失败27，SR73.2673%；Q2同集成功73、失败28，SR72.2772%。Q8运行源190/c68d4991，运行提交69a3bdb；全部首个完整结果保持。27例来自4个场景，不能作为完整1000泛化结论。

逐例交叉核对episodes.csv、导航观测轨迹、planner.log、复查事件、实际API crop与任务goals。全部27失败视频6538帧再次顺序解码，并人工检查关键步、最近位置、末帧及复查图；“全帧解码”不等于逐帧人工语义标注。

**距离含义：** `distance_to_goal`是机器人到该任务全部有效`VIEW_POINTS`的最小测地距离，不是到crop物体中心的直线距离。实际成功要求STOP且距离**严格小于0.20米**。离线从保存GPS与episode起始姿态重建世界轨迹，使用与评测一致的代理半径0.18米／高度0.88米／爬升和坡度设置生成分析用navmesh副本；不修改原始网格。27例最终距离复算与原CSV最大差4.77e-7米，表中最终值仍采用原CSV。沿途最近距离来自同一离线复算，未输入在线规划器。

## 主要结论

失败集中在马桶、盆栽、沙发：22/27（81.48%）。多数不是500步超时，而是**内部候选到达／停止与数据集有效目标位置没有对齐**，或者目标证据没有形成、在门边或极限探索中结束。

前三行共24例未耗尽500步；其中20例最终确实打印`Reach the object successfully`并主动结束。**这个日志是内部到达候选路径终点，不代表Habitat任务成功。** 三个`no frontier`标签还包含SEARCH_EXTREME后的停止，并不严格等于“整个场景没有未知区域”。

17个false positive中，7例曾被Qwen确认，2例只有uncertain（479/493），8例完全未调用Qwen。不能把17例都统计成视觉误认，更不能称Qwen准确率为导航SR。

## 确认后仍失败、未确认却停止

400/401/414的Qwen输入确实是深色沙发，均confirmed 0.95；500的输入也确实有马桶，confirmed 0.95。它们的复查候选簇中心投影与最近任务物体中心水平相距约3.19–3.31米／5.53米，最终停止点也不在有效观测点范围。证据支持“视觉类别确认后仍有目标实例／到达位置不匹配”，但仅靠crop和簇中心不能断言数据集漏标；大物体范围、不同同类实例与可到达观测点都需要区别。

444/446则更明确涉及**扶手椅／单座家具与couch任务范围混淆**：近处浅绿色家具被Qwen确认成couch，机器人在其附近停下，而数据集有效沙发中心在约3.7米外。444中远处沙发也获得确认，仍优先走了近处候选。446先执行26个补拍动作，二次2张图都是历史旧图，仍0.30不确定；随后确认的是另一个浅绿色家具候选，并非原候选被补拍确认。

433属于停止位置不满足阈值：40步曾到0.036米，但当时没有STOP；57步停止时为0.302米，比0.20米门槛多0.102米。不能解释为没看到椅子；Qwen已经确认两个chair候选。

另外10个false positive没有confirmed：406/417/419/440/457/459/462/464从未调用Qwen，479/493只有图像不足的uncertain。原ApexNav疑似目标／无可通行前沿回退和Q8后400候选靠近仍可选择这些目标，并沿原到达逻辑停止。**uncertain并没有被提升为confirmed，但仍能参与候选靠近。**

417/419/440在400步后分别明确靠近候选10、9、8→9，再于8.314／8.925／11.350米处STOP；不是“400步后未靠近”。459/462虽是tv失败，却均没有Qwen调用，且此前到过0.114／0.129米有效范围，之后疑似目标回退把机器人带到墙边，最后停止于1.721／1.787米。

## 超时与碰撞／探索过程

411和490都有一次Qwen初审（0.70／0.60，均insufficient），观测点规划均返回`no_safe_viewpoint`，没有第二次复查。400步后日志持续有`Annular late approach`，分别选择候选3／4。最后100步（401–500）各有14次前进、85次转向、1次终止STOP，累计移动约3.5米、净位移近0，目标距离分别维持1.402／6.964米。局部目标在两个相近位置间变化，轨迹呈短距离往返与转向循环；并非前进动作持续撞住，也并非没有进入靠近分支。

480不同：目标类融合分始终0，所有已关联图片中没有目标类可用crop，未触发Qwen；400后没有可排序的目标候选。它继续探索并脱困，88步已进入有效范围、451步最近0.002米，最终仍未STOP于有效位置，500步终止时距离4.280米。

408/452/467/474末段均有重复`Still stuck at the same place`与`Stuck for too long`。最后50步的前进命令中，位移小于2.5厘米分别为26/32、30/35、27/31、27/34。视频对应狭窄门框、墙边或破碎几何区域。可以确认“前进无法转化为位移、脱困未成功”；仅凭现有深度图和动作不能进一步把每次受阻唯一归于真实窄通道、重建伪障碍或二维地图误差。

410/466/487的目标类融合分始终0，Qwen调用为0；无可通行前沿后进入极限回退并按内部到达条件结束。487关键帧可见盆栽外观，最近0.020米，但未形成目标类证据。盆栽并非一概“没走到附近”，也不能一概归因Qwen拒绝：7个盆栽失败中只有411调用过Qwen，其余6例没有调用。

## 曾经过有效位置却未在当时停止

433、459、462、467、474、480、487共7例沿途最小距离小于0.20米，后来离开。467/474/480/487没有产出目标类可用crop和非零目标融合分；459/462有过目标crop，但未同时满足融合、主类别、观测次数等复查门槛。经过有效观测点只说明位置满足距离条件，不保证当时相机正对目标或识别已经成功。

因此这组失败存在重叠链条：目标证据不足／类别或实例范围不匹配→仍继续探索或候选回退→错过停止区域／门边受阻。报告按实际终止链给出互斥数量，语义、几何和停止因素不另行相加为独立失败数。

## 本地证据与限制

- 分析目录：`experiment_notes/qwen-frontier-oriented-20261116/failure-analysis/`。上级目录的`failure-details.csv`含27例路径、最终／最近距离、原因；`gNNNN-evidence.json`含复查／目标几何／末段运动，`gNNNN-timeline.json`含逐步距离与日志分段。
- `gNNNN-video-samples.jpg`为视频关键步对照，`gNNNN-qwen.jpg`为实际Qwen输入拼图；`final-gallery-1/2/3.jpg`覆盖全部27例末帧。图上任务位置仅用于事后分析，不参与在线决策。
- 原始视频索引仍为`experiment_notes/qwen-annular-400-500-20261116/delivery/failure-videos.csv`；原件与CSV未修改，未重新推理、未新增费用。
- 53,311个既有Q2/Q8证据、633个旧overlay文件、41原安装文件、18权重词表、17旧控制文件哈希检查通过；本窗口原件额外留有输入哈希。

确认调用只有11/27例，共17次复查；其中7例至少一次confirmed。27例中仅446真正执行额外观测（26动作），四例411/479/490/493请求观测后无安全点位。这些事实不支持将主要失败都归因于Qwen二次复查或环带执行。本文只报告已有证据与不确定性，不追加修改方案。
