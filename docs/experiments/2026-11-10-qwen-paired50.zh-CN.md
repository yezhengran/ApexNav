# 原 ApexNav 与 Qwen 复核：固定 50+50 最终报告

2026-11-10 启动，2026-11-11 完成验收。用户确认的两组各 50 回合均 `completed/0`，评测、规划器与四个模型服务已退出。本轮原始证据保留；此前实验数据和十份旧报告按用户要求清理，不混入本轮。

## 结论

Qwen 组成功 42/50，基线 38/50，净增加 4 回合；SPL 增加 4.69 个百分点。但 49/50 对回合在首次复核前已经出现动作分歧，仅第 44 对动作完全一致；不能把差异全部归因于 Qwen，也不能用导航 SR 代表模型准确率。本次比较的是原方法与已确认的额外复核整套机制，不是相同轨迹下只替换 VLM 的因果消融。

主要问题有三类：未触发复核的接近/探索超时或受阻；输入只覆盖目标局部，第二次观测未稳定改善信息；可见物体与任务有效目标集合不一致。四个 Qwen TV 失败的来源实际是场景中的真实壁挂电视，但该实例不在任务认可的目标集合中。让模型更容易确认“这是电视”不会自动解决这类评测失败。

### TV：语义物体与有效任务目标不一致

离线读取本轮场景和任务文件，并用保存的位姿、RGB、mask 重建八张 TV 来源图。Habitat 会按场景内容顺序重编号 episode，因此使用运行编号对应的内容索引，未按原 JSON 的旧 episode_id 错配。

八张重建 RGB 与保存原图的平均像素绝对误差为 0.0006–0.0082（0–255 标度），超过 99.95% 像素的各通道差≤3。语义 mask 主要覆盖 **`wall tv_231`**（部分含下方 speaker）；该任务 `tv_monitor` 的有效目标只有 **`monitor_353`、`monitor_354`**，位于另一处，八张 mask 内有效目标像素均为 0。基线五个 TV 失败视频也指向同一壁挂电视，但只有 Qwen 保存的八张源图进行了这种逐像素语义核验。

因此不能把它当作“画面不是电视”的负样本训练或强迫 Qwen 否定，也不能靠向在线系统提供有效 ID 修成绩。本轮官方指标原样保留。离线重建首次假定起点高度，g29 不吻合；改用导航网格实际地面高度后全部通过，两个分析记录均保留。这里只用真值解释失败，不参与在线动作或判断。

## 复核与观测机制

- 44 次所选候选复核请求，**全部由 STOP 触发**；本轮没有覆盖低置信触发链路。40/44 候选取得实际调用（90.91%），涉及 39 回合。
- 49 次 API 调用：26 confirmed、23 uncertain、0 rejected。23 次不确定中 21 次自报 quality=insufficient，2 次 adequate 但类别仍歧义；自报 quality 不是独立标注。
- 候选最终状态：26 确认、14 不确定、4 缺证据。缺证据发生在第 20、31、43、47 回合，前三例仍成功，第 47 失败。触发次数不等于 API 次数。
- 共 242 个额外观测动作。9 个候选使用第二次调用，其中 2 个转为确认、7 个仍不确定；新帧不一定带来更好的视角或完整度。没有明确否定，因此“撤销错误候选”的在线收益尚未被本轮验证。
- 人工查看全部 49 张实际 crop：床、沙发、CRT 电视通常可辨；多张马桶只剩水箱或窄条，椅子是残缺椅背/扫描纹理，部分壁挂电视被截断。第 33 第二图比第一图更局部，第 50 第二图只剩窄水箱。不是所有不足都能通过换模型补回。
- 所有实际调用的原始 RGB/mask 逐像素重建一致，原 mask 索引、观测帧、地图簇回执均匹配。没有 association_missing，每候选≤2 调用，STOP 来源均≤2 步，每回合 episode_end 为最后事件。
- API 请求总延迟 87.56 秒，平均 1.79 秒，最大 2.46 秒；正式导航估算费用 **0.040046 元**。含接口检查与失败快照保守预留的共享账本为 **0.061730 元 / 20 元**，未重置或清除预留。这是按用量估算，不是云账单结算金额。正式 49 次均完成，无 API 错误或静默降级。

## 下一步建议，尚未实施

先改善证据，再单独验证运动，不建议现在降低确认要求或继续换模型。

1. **同观测离线对照**：固定本轮图像与 Qwen，比较现有小 crop 和“全图标出所选候选框＋保留细节的 crop”。先人工区分可辨认、遮挡、语义与任务范围不一致，比较正确确定判断与错误确认；不能只追求更高确认率。类别目标和真值 ID 绝不输入模型。
2. **独立主动取景实验**：只有证据不足时，优先转向让目标进入画面，必要时使用原局部规划器给出的安全小幅退让/侧移；以边界截断减少、可见面积和有效视角变化选第二帧，限定动作预算，受阻及时退出。第二张没有新增信息就不浪费调用。具体预算和运动规则先对齐，再开发与完整导航对照。
3. 先保持触发、探索、目标选择、STOP 决策、模型与官方评测规则不变。超时/接近问题和 TV 任务范围问题单独分析，不混作观测模块收益。后续仍需报告首次复核前轨迹差异，不自动扩展新长实验。
